# 三角洲行动 · 钓鱼成本核算器

一个**离线、免安装**的钓鱼收益计算器。按你胸挂和背包的**真实格子布局**做精确
装箱计算，回答三个问题：

1. 这一趟最多能带回多少钱？
2. 能不能回本？还差多少？
3. 回本最少要钓几条什么鱼？怎么摆进包里？

---

## 特点

* **按真实格子算，不是按总格数算**
  胸挂/背包被隔板分成多个口袋，一条鱼不能横跨两个口袋；同样 24 格，
  一整块的能放下 2×3 的鱼，被切成两半的就放不下。

* **回本求解是严格的词典序最优**
  `minimize (条数, 占格)`，由精确分支限界搜索给出。
  界面会如实标注「已证明最少」还是「未证明理论最少」——**不会**把没证明的
  结论说成最少。

* **稀有度就是款式颜色**
  白色 → 绿色 → 蓝色 → 紫色 → 金色 → 红。同一条鱼在不同稀有度下颜色、
  尺寸、价格都不同，程序按「款式」而不是「鱼种」做库存单位。

* **水域筛选**
  内置 8 个水域的 27 种鱼分布，选钓点后只列出那儿能钓到的鱼。

* **纯离线**
  不联网、不收集数据、不写注册表。数据都在程序旁边的 `data\` 里，可自由编辑。

## 快速开始

### 方式一：用打包好的免安装版（推荐给使用者）

去 [Releases](../../releases) 下载 `DiaoyuCalculator-win64.zip`，
解压到任意目录，双击 `启动.cmd`。

**不需要安装 Python**，Windows 10/11 直接能跑。

### 方式二：从源码运行（给开发者）

需要 Python 3.10+（开发用 3.13），**仅标准库，无第三方依赖**。

```bash
git clone <本仓库地址>
cd DiaoyuCalculator
python main.py              # 打开图形界面
python main.py --check      # 数据自检，不开窗口
```

Windows 上也可以直接双击 **`启动测试版.bat`**（会自动找 Python，
出错时把错误留在屏幕上）。

## 使用说明

完整的操作说明见 **[使用说明.md](使用说明.md)**，
常见问题见 **[常见问题.md](常见问题.md)**。

三步上手：

1. **左栏** 勾选消耗品，自己选胸挂和背包（程序不会替你预设）
2. **右栏** 钓到鱼就点一下；**右键**可以切换稀有度/尺寸
3. **中栏** 看最高收益、回本线、最少几条回本，以及格子摆放图

> **关键操作**：左键加的是「当前款」（鱼块上写着，如 `红1X5`）。
> 如果你钓的是红色 1×5，必须先**右键**点鱼块选「红 1X5 [红]」，
> 否则左键会记成默认的金色 1×4 —— 尺寸和稀有度都不是你那条。

## 数据说明

全部数据都在 **`data/game.json`** 一个文件里，分四段：

| 段 | 内容 | 状态 |
|---|---|---|
| `fish` | 27 鱼种 / 59 款式 | 价格已录齐 |
| `chest_rigs` + `backpacks` | 19 胸挂 + 26 背包 | 布局已录，**6 款容量存疑** |
| `consumables` | 16 项消耗品 | 已录，**3 项价格存疑** |

这些数据来自玩家整理的价目表截图与布局表，**可能有个别录入错误**。
用之前请自己核对一遍。疑点在
[数据说明.md](数据说明.md) 里逐条标注。

改了数据后在界面里点「重新载入 data/」即可生效。

## 算法

求解器是本项目的核心：在带「口袋分组」约束的二维网格上做精确矩形装箱。

* 采用**填最左上空格**的分支限界，完备枚举保证最优性
* 不同颜色的口袋互不相通（一条鱼不能横跨两个口袋）
* 回本求解是 `minimize (条数, 占格) s.t. 价值 ≥ 回本线`

完整推导、失败实验记录、以及「哪些结论可以信」的说明：
**[docs/PACKING_ALGORITHM.md](docs/PACKING_ALGORITHM.md)**
